# Reproducibility and submission scope
Run `python training/train.py` from the project root after installing backend/requirements.txt. Models are fitted separately for USA, Australia, India and UK. Sri Lanka has no sampled cell in the supplied 5-degree archive; no model is claimed. UK has only two cells and is exploratory. All other countries retain the original archive dashboard where observations exist, with snapshot rather than historical model inference.

## Data and validation
The supplied NASA POWER archive is the source of every training observation: https://power.larc.nasa.gov/ (T2M, PRECTOTCORR, GWETROOT; MERRA-2). The CSV contains raw observations and derived features; holdout CSVs contain predictions. Baselines use 2011–2020; model fit 2021–2023; chronological holdout 2024–2025. No labels exist, so holdout anomaly fractions are descriptive, not accuracy. The grid is sparse point sampling, not national area coverage. The original proposal is retained unchanged as an aspirational design. The implemented archive uses air temperature, not LST, and soil wetness, not NDVI. Rainfall is mm/day, not monthly totals. The three seasonal statistical methods have fitted baseline parameters in seasonal_baselines.json. DBSCAN is transductive, not a predictive trained estimator; the algorithm is retained for future real fire observations, but is not run on the archive. No real historical fire dataset was supplied or downloaded. No simulated observations are included. No four-variable historical model is claimed.

## Missing satellite products / next steps
Network DNS was unavailable in the build environment. To extend the historical pipeline, acquire and harmonize MODIS MOD11A2 LST (https://lpdaac.usgs.gov/products/mod11a2v061/), MOD13Q1 NDVI (https://lpdaac.usgs.gov/products/mod13q1v061/), GPM IMERG (https://gpm.nasa.gov/data/imerg), and FIRMS archive (https://firms.modaps.eosdis.nasa.gov/download/). Apply quality flags, common spatial/temporal aggregation and explicit missingness; then refit a separate four-feature model. Do not treat absent fire data as zero detections. The submission is archive-only.
